# E-Commerce Sales Dashboard

An interactive **Power BI dashboard** designed to analyze and visualize e-commerce sales performance.

## 📌 Project Overview

This project transforms e-commerce sales data into meaningful business insights using Power BI. The dashboard provides an easy-to-understand view of sales, profit, products, categories, customers, and regional performance.

## ✨ Key Features

- Total sales and profit analysis
- Quantity and order performance
- Product-wise sales analysis
- Category and sub-category analysis
- Customer and regional sales insights
- Interactive filters and slicers
- KPI cards and dynamic visualizations
- Sales and profit trend analysis

## 🛠️ Tools & Technologies

- **Power BI**
- **DAX**
- **Data Modeling**
- **Data Analysis**
- **Data Visualization**
